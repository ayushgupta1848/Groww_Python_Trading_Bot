§ 02

How a Trade Decision Flows

From market open to order placed — this is the precise path a signal travels through the system before becoming a real options trade.

01
Market opens — raw data flows in
At 9:15 AM, three bots begin streaming live data simultaneously: calculate_oi_pcr polls NSE's option chain API every 60 seconds for Open Interest and PCR across all NIFTY strikes; Premium Direction Tracker polls Groww for live ATM CE/PE LTPs every few seconds; NSE Indices Monitor tracks breadth across all major sectors. India VIX is fetched from NSE every 2 minutes by the dashboard itself.
NSE API Groww LTP oi_snapshot.json logs/premium_tracker/
02
Analysis bots compute structure & momentum
Fibonacci Trend Analyzer computes multi-timeframe (1H, 15M) swing highs/lows and identifies which Fibonacci retracement zones (especially the 50–61.8% Golden Zone) the index is near, outputting BULLISH / BEARISH / NEUTRAL bias. Chart Level Analyzer scores daily, 1H, 15M support and resistance levels by strength (touch count, rejection quality, efficiency) and tells you if the current price is in a Green (safe to trade), Caution, or Wait zone. Trendline Scanner watches for ascending/descending trendline touches and fires BOUNCE or BREAK signals.
Groww charting API logs/fibo_analyzer/ logs/chart_level/ .trendline_signals.json
03
Master Signal Bot synthesizes all inputs into one vote
Every 60 seconds, Master Signal Bot ingests signals from all analysis bots and the OI snapshot, applies configured weights (1H: 35%, 15M: 40%, 5M: 15%, Premium: 10%), and outputs a single consolidated signal: ENTER CE, ENTER PE, or NO TRADE with a confidence score. It also reads BOT_TUNING.json (written by Signal Analyzer) each cycle to auto-apply corrections from previous session performance. The time gates (no trade before 9:30, no trade after 3:00) are enforced here.
CONFIDENCE ≥ 65% BOT_TUNING.json logs/master_signal/
04
Dashboard unifies everything — trader sees one screen
The Live Dashboard (Python HTTP server on port 8765) reads every log file and JSON from every running bot, rebuilds a unified snapshot every 15 seconds, and serves it to the browser. The trader sees: live consensus signal, VIX regime, OI bias, chart level zone, Fibonacci bias, premium flow direction, open positions, PnL — all on one screen without switching terminals. The dashboard does not place any orders — it is read-only except for PROD10 bridge commands.
:8765 15s refresh Read-only (except PROD10 bridge)
05
Trader decides — manual, quick, or fully automatic
The trader has three modes: Manual (reads all signals, decides independently, uses PROD10 Trade Board to enter), Quick Trade Mode (one-click instant MARKET order from the option chain — no confirmation dialog), or Fully Auto (Momentum Auto Bot, Scalping Auto Bot, or Live Pattern Scanner trade autonomously with their own entry/exit logic). In Quick Trade Mode, the system auto-calculates max affordable premium from your F&O balance and grays out strikes you can't afford.
Manual Quick Trade Auto
06
PROD10 places the order via Groww API
The dashboard writes a bridge command to .prod10_bridge_cmd.json. The PROD10 bot's bridge-watcher thread picks it up within 10ms. A MARKET BUY order fires immediately — no pre-order LTP fetch (eliminated to reduce latency). If VALIDATE=ON, the bot waits for EXECUTED status, fetches the actual weighted-average fill price from /v1/order/trades/{id}, and sets the limit SELL target at fill + quick_pts. If VALIDATE=OFF, it uses the dashboard chain LTP as an estimate. Total latency (click → order placed) is approximately 1 second with persistent session, vs 6 seconds without.
.prod10_bridge_cmd.json MARKET → avg fill → LIMIT target ~1s latency
07
After session — feedback loop closes
Signal Analyzer reads logs from Fibonacci, Premium Tracker, and Master Signal to evaluate which signals led to wins and which didn't. It auto-generates BOT_TUNING.json with corrected weights, exclusion patterns, and directional multipliers. Next session, Master Signal Bot picks up this file on its first cycle and self-corrects — without any manual intervention. Analyze Bot (with optional OpenAI narrative) generates a full performance report. Personal Trading AI compares today's trades against your 3-year history for pattern-level advice.
BOT_TUNING.json logs/analysis/ Self-correcting

Three Ways to Trade

MANUAL MODE
PROD10 + All Analyzers
You read all signals, make the decision, and click BUY CE or BUY PE on the Trade Board. Full control — the system is purely advisory. Best for learning the signals and developing conviction.
  1. Run all analyzer bots + PROD10
  2. Open dashboard → Trade Board tab
  3. Check consensus signal + VIX + chart zone
  4. Click strike → confirmation dialog → confirm
  5. Monitor PROD10 STATUS for fill + target set
⚡ QUICK TRADE MODE
PROD10 ONLY
One-click instant MARKET order from the option chain. No confirmation. Capital auto-fetched from Groww or entered manually. Over-budget strikes grayed out. Chain auto-refreshes every 5 seconds. Optimized for speed.
  1. Toggle ⚡ Quick: ON in Trade Board
  2. Set CAPITAL SRC to API or Manual
  3. Fetch capital → MAX PREM calculated automatically
  4. Click any enabled BUY CE / BUY PE → order fires instantly
  5. PROD10 fetches actual fill → sets limit target
AUTO MODE
Momentum / Scalping / Pattern
Run one or more auto-bots. They observe, decide, enter, manage SL, trail, and exit completely without you. You can monitor via the dashboard but no action is required. Circuit breakers prevent runaway losses.
  1. Choose a bot: Momentum (velocity), Scalping (ORB), or Pattern (3 setups)
  2. Configure via override JSON (live — no restart needed)
  3. Run the bot in terminal
  4. Monitor Dashboard → Scanner / BOT STATUS bar
  5. Review trades in logs/trade_history/ at end of day
§ 06

Advantages

What this system does well
  • Multi-layer signal consensus. No single indicator decides. Fibonacci + OI + Chart Level + Premium flow + Trendline all vote before Master Signal outputs anything — dramatically fewer false entries compared to a single-indicator system.
  • Self-tuning feedback loop. Signal Analyzer → BOT_TUNING.json → Master Signal. The system gets smarter session-over-session without manual intervention. Wrong thresholds correct themselves.
  • Quick Trade latency of ~1 second. Persistent HTTP sessions eliminate the 2–3 second TCP/TLS overhead per API call. Dashboard LTP hint skips the pre-order fetch. MARKET order fires the moment you click.
  • VIX-aware execution. All auto-bots adjust velocity thresholds based on VIX regime. In a VIX >22 environment, momentum thresholds automatically rise — you won't enter on the same 0.5% move that would trigger in a VIX 14 session.
  • Live config without restarts. Every key parameter (target points, lots, mode, partial %, ATR source) reads fresh from the dashboard or override JSON on every trade cycle. Change mid-session, takes effect immediately.
  • Capital-aware option chain. Quick Trade Mode auto-fetches your F&O buy balance, calculates max affordable premium per-lot, and grays out strikes you can't afford. No accidental oversize entries.
  • Comprehensive logging at every layer. Every bot writes structured logs. ANALYZE_BOT and SIGNAL_ANALYZER can reconstruct exactly what happened in any session — what was signaled, what was entered, what the outcome was.
  • Personal AI advisor uses YOUR history. Unlike generic backtests, PERSONAL_TRADING_AI analyzes your 3 years of actual trades to find your personal edge windows — specific times, setups, and market conditions where you historically perform best.
  • Paper and Mock modes on every execution bot. Any execution bot can run in PAPER (simulated fills, no orders) or MOCK (logs actions, no Groww API calls) — safe for testing new configs during live market hours.
  • ATR-based adaptive stop-loss. SL distance uses Historical ATR or Tick Range — it adapts to the volatility of each session rather than using a fixed point stop that is too tight on high-VIX days and too loose on calm days.
  • One screen for everything. The dashboard unifies output from 17 components into a single browser tab. No terminal switching, no mental state aggregation — the consensus is already computed for you.
  • Circuit breakers on auto-bots. Live Pattern Scanner blocks itself for the day after 2 consecutive SL hits. Momentum Auto Bot enforces cooldown between trades. You cannot accidentally revenge-trade through an auto-bot.
§ 07

Disadvantages & Limitations

What to watch out for
  • NSE API is fragile. NSE's allIndices and option-chain endpoints require browser-like cookie sessions and rate-limit aggressively. The VIX fetch loop and OI bot can go silent for minutes during high-traffic periods (market open, major events). You must monitor the BOT STATUS bar for staleness.
  • Single-broker lock-in. The entire execution layer is built on growwapi + Groww's specific order endpoints. Migrating to Zerodha, Upstox, or Angel requires rewriting every order placement function. No abstraction layer exists.
  • growwapi library maintenance risk. The growwapi Python library is a third-party wrapper that has broken before when Groww updated their internal API. When it breaks, all auto-bots stop working until the library is patched.
  • In-memory state. Most bot state (OI history, VIX ticks, open position data) lives in RAM. A server crash mid-trade means the bot has no memory of its open position — though VIX is now cached to disk, most other state is not.
  • High operational complexity. Running the full system requires starting 8–10 separate processes in separate terminals. There is no single start command, no process manager, no watchdog that auto-restarts a crashed bot.
  • Fibonacci and trendlines are lagging. These tools work on past candles. In fast, news-driven moves (RBI announcement, global shock), the analysis layer may signal "BULLISH" from structure while the market is already down 1%. The convergence bot is the only early-warning component.
  • Log file accumulation. Every bot writes timestamped log files with no automatic rotation or deletion. After months of running, log directories can grow very large and slow down the regex-based dashboard parser.
  • Personal AI requires careful data hygiene. PERSONAL_TRADING_AI is only as good as your historical trade data. Gaps, formatting inconsistencies, or data from a different strategy era will produce misleading recommendations.
  • Only simple option buys supported. The execution layer handles single-leg MARKET BUY → LIMIT SELL. Spreads, straddles, strangles, ratio spreads — none of these multi-leg strategies can be placed through this system.
  • Race conditions between auto-bots. If you run Momentum Auto Bot AND Scalping Auto Bot simultaneously, both can enter positions in the same underlying at the same time. There is no cross-bot position coordination or mutual exclusion.
  • OI data can lag 3–5 minutes. NSE publishes OI updates with a delay. calculate_oi_pcr polls every 60 seconds, but the underlying NSE data may itself be 3–5 minutes stale. OI bias signals should be treated as background context, not real-time flow.
